# Decisions

Trade-offs recorded so they are not repeatedly questioned or quietly "corrected". Each one
looks like an oversight from the outside and is not.

If you are about to change something on this list, the burden is to show that the trade-off
has changed — not that the current state is imperfect. It is.

A decision that governs one shipped contract (an API, a guide) lives in that contract
document instead; this file holds the ones with no better home.
